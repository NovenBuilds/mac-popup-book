# 《开合之间》成品验收标准

五页合订包逐页验收。林间小屋已有的相处动作、存档和声音是回归基线。其余页以每页原设计的主要体验为范围。各页使用同一验收标准。

| 项目 | 通过条件 |
| --- | --- |
| 美术 | 展开后主景占据可阅读的画面，核心操作点不用读说明即可辨认。页面具备纸页、书脊、折痕和前后层次。主角和可动件有可辨认的分件、材质和颜色，采用统一纸艺语言。 |
| 动作 | 核心输入立即有可见反馈，至少两种操作结果在画面中可辨。角色用动作表达状态，机构沿连接点运动。快速重输、反向和切页均保持连续。 |
| 声音 | 每页至少有一个与核心操作同步的短声；持续环境声按场景需要加入。启用、静音、收合和离页都要验证；反复操作无叠声尖峰或旧页串声。 |
| 开合 | 收合、半开、全开各有稳定轮廓。结构依附折线，收起的主角能自然回位或被遮挡。慢合和快合均无明显穿插、悬空、瞬移或重复出场。手动开合与物理铰链使用同一场景进度。 |
| 操作 | 鼠标、触控板和窗口内替代控制都可完成核心玩法。简中与英文提示与画面一致，主操作标签在正常窗口尺寸可读。 |

逐页记录下列可观察结果。

- 林间小屋：邀请、轻抚、半开和合上后恢复。回到小屋时相处记录可用。
- 口袋小镇：两条环线各自触发可见的街景回应；道岔有明确位置、可用状态和声音；列车能驶离、回站和收起；按整车包络检查 72° 至 107° 两条环线的净空。
- 窗边小屋：三段时光有明确灯光和角色动作；快速拨动时最终目标正确；座椅、书桌和床边的动作对齐家具；61° 至 64° 停住和反向时，房客保持实体且姿态连续。
- 海底剧场：两个方向能让鱼群产生不同轨迹；鱼尾、海草和水纹表现方向；松手恢复巡游；在半开及 100° 以上固定取帧，验证物种分层和独立运动。
- 机械天文馆：曲柄、轨道和日地月联动；正向、反向、暂停清楚；观察点能看到所描述的受光变化；切页后恢复相位；在 100° 以上固定取帧，验证日地月机关继续运转。

后台检查记录三档展开画面、连续切页、交互和进程状态。实机检查记录物理铰链与试听，使用同一候选构建。
