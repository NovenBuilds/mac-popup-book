# 《开合之间》五页试用交接

候选版本 0.2.1（构建 4）。从干净的候选源码提交运行以下命令，构建与验收都由同一源码指纹约束。

```sh
bash scripts/verify-candidate.sh
```

脚本生成 `build/开合之间.app`、构建凭据和 `build/candidate-checks/result.json`。三份日志分别记录工程检查、后台隔离和五页集成。每次运行的离屏截图和日志路径在验收凭据的 `evidence_dir` 中。这一步生成供本机验证的临时签名包。

## 外部候选包

在本机钥匙串配置 Apple 开发者签名证书和公证工具的钥匙串配置。将证书身份设为 `POPUP_BOOK_SIGNING_IDENTITY`，将公证配置名设为 `POPUP_BOOK_NOTARY_PROFILE`，然后运行：

```sh
python3 scripts/package-beta.py
```

输出目录 `build/external-beta/0.2.1-4` 包含 ZIP 压缩包、SHA-256 校验值、签名后构建凭据、自动验收凭据和试用说明。公证、附票或系统安全检查失败时不生成交付目录。签名身份和公证凭据在本机维护。

## 实机与外部试用记录

用同一包记录候选提交、包校验值、Mac 机型、系统版本和显示分辨率。对照[五页成品验收标准](RELEASE_ACCEPTANCE.md)，每页保存收合、半开、全开和核心互动的结果。

| 验收 | 操作和记录 |
|---|---|
| 物理开合 | 慢开、快合、半开反向、合盖唤醒。小镇超过 90° 运行，模拟或复现实测信号失联时检查暂停和恢复。 |
| 输入和声音 | 各页用鼠标、触控板、替代按钮至少各操作一次。切换手动、静音和翻页，检查提示、声音、旧页串声和可重试状态。 |
| 性能 | 在固定分辨率记录首翻耗时、前台帧耗时、连续 30 分钟的内存走势、静置功耗、天文馆写入次数。将前台数据和离屏记录分开。 |
| 异机安装 | 在没有开发工具的 Apple 芯片 Mac 下载并校验 ZIP，解压到应用程序目录，验证首次启动、五页、手动开合、重启恢复。 |
| 首次试玩 | 3 位真实铰链用户、2 位纯滑块用户。从首屏可操作开始计时，至少 4 位在 20 秒内自行完成展开和一次核心互动。记录误点、是否继续翻页、阻断与复测。 |

证书、公证配置、异机和真人结果分别登记。实际缺少的前置条件记为待验收。
