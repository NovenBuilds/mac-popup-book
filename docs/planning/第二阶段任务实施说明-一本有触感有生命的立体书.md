## 1．体验目标与范围

采用纸质书页、折叠小屋与风格化立体猫，保留橘白猫、奶油纸、森林绿和暖窗灯。猫应能被近看，半开场景也能成立。必做资产样件、动作库、运行验证与美术替换；不增加章节、第二只动物或复杂开放世界。

## 2．前置条件与现状差距

依赖第一阶段通过：行为、连续交互、声音、v1记忆与动作需求。当前基线使用代码纸片几何，没有已验收的骨骼角色；Tripo、Blender安装、账号、预算和专业制作能力均未确认。先检查现有工具，缺工具列安装任务，禁止默认已安装或默认购买。

## 3．产品行为与资产规格

### 3.1 视觉与资产流水线

1. 制作同一只猫的正侧背参考、表情和全景样张，三个开合状态使用相同设计。保留纸艺触感，避免写实毛发与厚重塑料。
2. 用自有或许可明确的参考在Tripo3D生成最多3个猫初稿候选，只用于比较；优先挑选轮廓、四肢、耳尾可分辨的版本。
3. Blender为主源：清理网格、重新整理不适合变形的关节区域、修正UV贴图、绑定与权重、材质和动画；自动生成不等于可直接交付。
4. 本轮默认不购买服务。Tripo不可用、额度不足或商用权未落实时，转用Blender自制简模完成同一流程；不得把免费试验资产带入正式包。需要付费提升质量时输出价格/权利/工作量清单待确认。
5. 每项资产保留 `.blend` 源文件、贴图、导出脚本及运行产物。运行交换优先验证USD/USDZ（通用场景描述资产），GLB（三维二进制交换文件）作为中间验证格式；真正交付格式由导入样件结果确定并锁定，不凭扩展名宣称兼容。

### 3.2 样件、动作与运行规格

首个样件只做猫、门、台阶、猫垫和一组折叠树。必须同时验证静态造型、骨骼动画、材质、声音位置、命中与存档恢复。

| 动作片段 | 播放与衔接要求 |
|---|---|
| 睡眠/坐卧 | 可循环，无明显接缝；呼吸不造成漂移 |
| 醒来/伸懒腰 | 可从当前姿态淡入，收合随时中断 |
| 行走/转身 | 原地循环由表现层匹配路径速度，避免根位移重复叠加 |
| 坐下/起身 | 明确起止姿态，坐垫位置对齐 |
| 整理毛发 | 可提前收尾，不硬切回标准站姿 |
| 接受抚摸 | 头部朝接触点微调，耳尾不过度抖动 |
| 邀请回应 | 区分看到邀请、接受/婉拒、行动 |
| 告别/回屋 | 慢合完整，快合压缩，门后自然隐藏 |

视线、眨眼、耳尾和呼吸是可叠加的表现层控制，不各自占一个互斥大状态。默认过渡150～300毫秒，继承第一阶段打断规则。不能直接把人形舞蹈套到四足猫。

资产坐标统一：米制、Y轴向上、猫朝+Z，角色根在地面中心；导出轴变换集中在脚本。折叠机关用命名转轴，不烘焙不可修改的单体网格。首轮性能预算：猫≤5万三角面、常用贴图≤2048像素、总场景≤30万三角面；超出需提交实际帧时间证据再调整，不机械追求面数。

### 3.3 渲染方案决策门

默认保留SceneKit。RealityKit只做隔离样件，使用同一猫、路径、折叠进度与测试输入比较。通过条件：覆盖macOS14目标所需能力；骨骼片段、连续姿态、命中、声音、窗口生命周期全部可用；三个角度与十轮打断无新增缺陷；同等画质下95百分位帧时间不劣于现有实现超过10%，无持续内存增长。

只有全部通过才迁移；否则保留SceneKit并记录失败项，不为框架升级推迟三维猫交付。若两条导入路径都不能可靠播放，同步停止批量制作，先修导出或简化绑定；不能退回静态模型冒充动作验收。迁移时新增独立后端模块与对应猫表现/场景适配，不让核心和行为模块导入新图形框架；发布只选一个默认后端。

## 5．工程与素材要求

- 模型与动画放角色表现资源，书页/屋/树放场景资源；行为输出语义姿态，表现层将姿态映射动画，不在业务层保存骨骼索引。
- 动作清单明确片段名、循环性、起止姿态、允许中断点、脚步事件、根位移策略和时长。缺必需片段阻止交付并显示错误；耳尾细节缺失可用明确的静态退路。
- 网格、材质、贴图与骨骼导出可复现；源文件与运行产物使用校验清单对应。许可明确允许随源码仓库分发的源文件进入工程资产源目录；只能随应用分发的第三方源不进入公开仓库，须改用可公开资产或确认独立受控交付方式。不能因“可商用”就推断可以公开源文件。
- 音频源推荐48kHz无损WAV；保留编辑原始文件，运行时可另编码。对白不引入真人台词。具体素材使用权逐项登记作者、链接、许可、日期、修改和署名。

## 6．测试与验收

**自动检查：**必需节点/骨骼/片段/材质存在；边界盒与缩放合理；导出资源不引用绝对路径；行为重放及存档兼容；动作中断、混合权重与声音事件不重复。

**本机验证：**在展开100%、半开50%、近合5%固定视角输出；真实慢开快合、行走中反向、抚摸中回屋各十次；调试显示脚底/锚点，走路无肉眼明显滑步，身体不穿台阶和门。标准模式目标接近60帧；30分钟测量帧时间、内存、CPU/GPU及热状态，与S1同条件比较。

**真实体验：**相同十分钟过程比较纸猫基线与立体版本，记录亲近感、表情可读性、触碰可信度与纸书辨识度。画面更精细但动作不连贯，不能验收为升级完成。
