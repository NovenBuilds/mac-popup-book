
# 《林间小屋》立体绘本：第一版实施计划

## 1．目标与体验

制作一个可窗口运行、可全屏的 macOS 独立应用：**屏幕展开，纸上的森林和小屋逐层立起来；猫醒来、走出门；收合时，猫回屋、窗灯亮起，场景重新叠回纸面。** :codex-annotation{index="1"}

第一版采用温暖纸雕绘本风格，重点验证三个体验：纸机关是否跟手、猫是否有生命感、反复展开是否仍然有趣。

已确定的边界：

- 一个森林小屋场景、一只猫、一个点击互动。
- 支持真实铰链角度和手动预览。
- 少量音效，默认静音。
- 暂不做桌面覆盖、开机启动、锁屏演出、多章节、喂养和联网功能；应用随系统正常睡眠。

## 2．场景与角色设计

**场景构成**

采用固定观察视角，画面下方是打开的纸页和折痕；森林、小屋从纸面向上展开。保留纸片边缘、薄厚和柔和阴影，避免看起来只是插画缩放。

由远到近分为五组：远山与天空、后排树木、小屋、前景草丛、猫与门前小径。各组围绕自己的纸质折线旋转，展开区间相互交叠，收合时按同一路径反向运动。

美术统一为奶油色纸张、低饱和森林绿、暖棕木屋、橘白猫和淡黄色窗灯。界面只保留场景与底部可隐藏的控制条。

**猫的行为**

| 场景阶段 | 猫的表现 |
|---|---|
| 接近收合 | 藏在屋内，不露出纸页 |
| 逐渐展开 | 窗边出现猫，抬头、睁眼 |
| 接近完全展开 | 伸懒腰，然后走到门前 |
| 展开后停留 | 坐下晒太阳，偶尔眨眼、摆尾 |
| 点击猫 | 转头看向用户、抬爪；声音打开时轻叫一声 |
| 开始明显收合 | 转身回屋，窗灯亮起，随后随小屋一起折回 |

角色用分件纸偶制作，身体、头、尾巴与四肢可独立运动。第一版通过姿态、位移和节奏表现动作，不制作复杂三维骨骼。

**动作优先级**

纸机关始终服从角度，不等待猫完成演出。缓慢收合时完整展示回屋；快速收合时缩短动作，并在门后隐藏。中途反向打开时，从当前姿态平滑衔接，不瞬移、不重新播放整个开场。

点击回应只在猫已出屋且场景接近展开时有效；动作期间重复点击不排队。收合可立即打断回应。

## 3．角度交互与应用实现

**角度规则**

- 默认以 **35°为收合、105°为展开**，限制映射结果在 0～100%。正常试用不需要完全合盖。
- 提供“将当前角度设为展开位置”，允许在 80°～120°内校准，并保存选择。
- 提供手动进度滑块和“跟随屏幕”切换；手动模式不读取角度。
- 纸机关采用约 60 毫秒的轻量平滑，不添加明显弹跳。
- 角色出屋条件：展开进度达到 85%，并稳定约 0.5 秒；收合至 75%以下开始回屋，避免临界位置反复触发。
- 停止开合时，纸机关保持当前位置；猫与环境继续进行低幅度动作，不像桌面动画工具那样自动恢复。

**技术方案**

使用 **Swift（苹果原生开发语言）** 编写应用，**SwiftUI（原生界面框架）** 实现控制界面，**SceneKit（三维场景框架）** 实现纸片层级、转轴运动、遮挡和灯光。音效使用系统音频框架，不依赖额外 Metal 编译组件。

内部拆成三个独立部分：

- **角度输入**：输出角度、采样时间和连接状态；读取放在后台执行，前台约每秒采样 30 次。
- **绘本状态**：把角度换算为展开进度，协调运动方向、角色动作和点击回应。
- **场景表现**：只消费展开进度与角色状态，不直接访问硬件；真实输入和预览共用这条路径。

读取方式参考已验证项目，重新编写小型适配层，不修改收藏仓库。自有工程放在 `/Users/ssr/project/mac-duo/popup-book/`，应用产物放到现有 `apps/` 目录，不覆盖现有试用工具。

**恢复行为**

传感器连续约一秒不可用时保持最后画面，显示简短提示并提供手动预览；恢复后平滑接回真实角度。窗口最小化、应用进入后台和系统睡眠时停止采样及动画；回到前台后重新读取。

首版目标为本机 M1 Max、macOS 14及以上、Apple Silicon 本地构建。不请求屏幕录制、辅助功能或输入监控权限，不使用锁屏私有接口。

## 4．素材与制作顺序

按三个阶段推进，每阶段都有可检查的结果：

1. **纸机关原型**  
   用简单色块搭建纸页、树、小屋和猫占位物。完成角度读取、预览、展开、反向收合及前后台恢复，先验证空间结构。

2. **纸雕美术与猫动作**  
   先制作一张展开状态的视觉定稿，再按同一设计生成或绘制独立透明素材。主体素材按约 2048 像素级准备，猫分件按约 1024 像素级准备；保留生成来源和后续加工记录。替换占位物，完成猫的醒来、伸懒腰、行走、坐下和抬爪。

3. **氛围与交付**  
   加入缓慢摆叶、窗灯、纸张轻响和猫叫。声音默认静音，开启后才播放；音效不随每次传感器抖动反复触发。完成应用打包、启动入口和中文使用说明。

必须同时检查完全展开、半展开、接近收合三种画面，不能只凭一张漂亮的展开图验收。

## 5．验证与验收

**自动检查**

- 角度映射、校准范围、边界值和异常输入。
- 猫的出屋、回屋、点击打断及中途反向转换。
- 传感器丢失、重新连接及前后台切换后的状态恢复。

**本机体验验收**

- 慢开、快开、停住、反向收合时，纸片连续跟随；无明显跳变、穿插或角色瞬移。
- 半开时确实能看见纸片的纵深、折线和遮挡，透明素材不露出矩形底板或阴影。
- 连续开合十次，猫始终能回到合理位置，不重复堆积动作。
- 点击回应可中断，默认静音有效，切到后台后声音与动画停止。
- 物理合盖后仍正常睡眠；唤醒并回到应用时，可继续使用，不承诺唤醒瞬间演出。
- 在本机默认画质下，以流畅接近每秒60帧为目标；记录实际帧率与前后台资源占用，不以“编译通过”代替视觉和硬件验证。

交付物为可运行应用、完整自有源码与素材、中文启动说明，以及区分自动检查和真实开合测试的验收记录。
