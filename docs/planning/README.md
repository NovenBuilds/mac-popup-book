# 林间小屋 · 第一版

一个随 MacBook 屏幕开合而展开的纸雕绘本。Swift、SwiftUI、SceneKit；macOS 14+，Apple Silicon。本版独立运行，没有桌面覆盖或锁屏功能。

## 直接体验

打开上一级 `apps/林间小屋.app`，或在实验目录执行：

```bash
bash ./试用林间小屋.command
```

- 默认跟随真实屏幕：35°收合、105°完全展开。可在80°～120°内点击“校准展开位置”，校准结果会保存。
- 关闭“跟随屏幕”，拖动进度滑块，即可不动屏幕体验全部过程。
- 完全展开并停留片刻，猫会醒来、伸懒腰、走到门前。点猫，它会抬爪回应。
- 慢慢收合，猫会回屋；快速收合时动作压缩，不强迫纸机关等待角色。
- 小喇叭默认关闭；主动打开后有纸张轻响、合成猫叫和轻环境声。声音选择会记住。
- 控制条可收起，底部“显示控制条”可找回；右侧全屏按钮或系统绿色窗口按钮切换全屏。
- 切到其他应用、最小化或睡眠后，角度采样、动画和声音暂停，回到前台继续。
- 传感器暂不可用时保持当前画面，并提示切换手动模式。

不需要屏幕录制、辅助功能、输入监控或麦克风权限。不要为本应用修改锁屏或系统睡眠设置。首次体验建议先退出 macTilt / ClamShell，避免它们的桌面动画影响观察。

## 构建和检查

在本目录执行：

```bash
bash build.sh
bash test.sh
```

需要本机 Xcode 或含 SwiftUI 与 SceneKit 的开发工具；无需额外 Metal 编译组件。普通受限执行环境可能不允许系统界面宏插件启动，应在正常本机终端编译。构建只输出上一级 `apps/林间小屋.app`，采用本地临时签名，不安装至系统应用目录。

`Tools/RenderCheck.swift` 用于导出展开、半开、收合图与离屏渲染速度；`Tools/LifecycleCheck.swift` 检查实际计时器和模拟生命周期通知；`Tools/ExportAudio.swift` 可重新导出音效。离屏快照速度不是应用实时帧率，模拟通知也不是物理合盖验证。

完整检查命令见 `verify.sh`。它会运行图形检查，前台生命周期检查会短暂激活一个测试程序。

## 工程结构

- `Sources/BookState.swift`：角度映射、60毫秒平滑、角色状态和可打断的进出屋动作。
- `Sources/LidInput.swift`：后台约30次/秒读取窄匹配的苹果铰链传感器，只读，不访问键鼠。
- `Sources/PaperScene.swift`：所有纸雕轮廓、厚度、折线、灯光、分件猫和场景动画。
- `Sources/BookModel.swift`：输入切换、前后台管理、校准保存、声音和界面连接。
- `Sources/ForestBookApp.swift`：中文界面、全屏、预览滑块、猫的鼠标命中。
- `Sources/BookAudio.swift`：原创程序合成的音效及暂停恢复。

## 素材来源与边界

本版所有场景轮廓与猫均为代码原创绘制的矢量几何，不来自上传图片、第三方素材或生成模型；不是由位图自动描摹而来。形状有真实薄厚，没有承载插画的透明矩形平面。素材直接由 `PaperScene.swift` 构建，故不受2048/1024像素分辨率限制。

`artifacts/open.png` 是最终几何场景的展开视觉参考，`half.png` 与 `closed.png` 为同一场景检查图。它们不是独立概念画，也不作为运行时背景贴图。`Resources/Audio/` 的 WAV 是同一声音算法导出的副本；程序本身可重新生成。

传感器报告格式参考本机已验证的 ClamShell 与 macTilt 行为，适配代码为独立实现；未修改任何收藏仓库。兼容性首先以当前 M1 Max 本机为目标，未宣称验证所有机型。

已验证与待验证项目见 `验收记录.md`。本版为风格与交互可体验的原型；尚未制作更精细的纸纤维材质或逐帧手绘角色动画。
