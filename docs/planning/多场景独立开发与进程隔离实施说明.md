# 多场景独立开发与进程隔离实施说明

日期：2026-10-27。代码工程：`/Users/ssr/project/mac-popup-book`。

本轮完成整书底座、《林间小屋》独立场景迁移及两个契约测试页。未开发五个正式新跨页，未恢复原七阶段深化计划，未推送远程。产品范围仍参考[六跨页规划](开合立体书-六跨页场景与整书规划.md)；证据和限制见[验收记录](多场景工程整理验收记录-2026-10-27.md)。

## 1. 工程结构

| 路径／模块 | 职责 |
|---|---|
| `Modules/PopupBookCore` | 值类型、角度规则、页面描述、类型化输入输出和契约版本 |
| `Modules/PopupBookRuntime` | 注册表、整书状态、切页状态机、页面健康状态与故障恢复 |
| `Modules/MacPlatform` | 唯一铰链入口、显示时钟、进程监督、声音作用域和隔离存储 |
| `Modules/PageTransport` | 进程间消息与安全编码约定 |
| `Modules/PageWorkerKit` | 场景进程接入、离屏渲染、共享缓冲池和释放流程 |
| `Modules/SceneKitRendering` | 通用纸片几何、取景与交互命中 |
| `Apps/BookHost` | 整书界面、目录、共享画面显示和依赖组装 |
| `Scenes/forest-cabin` | 独立 Swift 包：猫行为、猫表现、森林场景、工作进程、素材及测试 |
| `Scenes/contract-red`、`Scenes/contract-blue` | 独立开发／故障验收用测试页；不进入正式目录 |
| `Templates/Page` | 新场景包模板，包含行为、工作进程、测试和接入描述 |
| `Experiments/VolumeCat` | 保留既有立体猫实验与运行工具，不注册为正式页面 |
| `Experiments/LegacyForestApp` | 历史单场景应用源码，供追溯，不作为正式入口继续维护 |

根包发布共享库，不反向依赖任何具体场景包。场景通过根包库产品接入；角色内部姿态仍保持行为与表现的类型匹配。无需角色的页面不伪造猫或其他角色。

## 2. 注册和接入

每页提交自己的 `Scenes/<id>/page.json`，包含稳定标识、名称翻译、契约版本、服务标识、构建产品、音效资源及可选旧存档文件名。发现页面与发布页面分开：

- 开发工具发现本地包；损坏或不兼容描述被诊断。
- `Book/published-pages.json` 由集成者维护正式顺序，目前只有 `forest-cabin`。
- 严格发布构建必须包含全部已启用页，不能编译失败后静默漏页。
- 运行时单页描述、资源或服务异常只影响该页；零可用页仍显示书壳与诊断入口。

场景实现 `RenderedBookPage` 适配器：准备、输入、推进、渲染、暂停与结束。主程序提供时间、展开上下文和存档快照；页面返回画面、文案、通用操作、无障碍描述、声音命令和状态快照。页面不能直接打开铰链、播放系统声音或改真实用户存储。

## 3. 状态与故障隔离

整书状态由 `BookCoordinator` 集中变更，界面只发送意图。切页经历准备、折平、翻纸、展开；进程健康状态与本页玩法状态分别管理。连接代次、画面池代次与帧序号用于拒绝旧画面、旧声音和迟到存档。

正式页面运行在应用内 XPC（独立进程通信服务），通过 IOSurface（跨进程共享图像缓冲区）提供画面。三块有限缓冲区只有在子进程完成写入、主程序完成读取后才能复用；无空闲缓冲时跳过过期帧，不无限排队。共享画面统一为 BGRA8、sRGB 色彩空间。

启动十秒未就绪、前台活动三秒无有效画面推进、服务退出或无效协议消息均进入页面故障。后台和主动暂停不计卡死。故障后提供手动重试和切换页面，不无限自动重启。目标准备失败保留旧页。声音按页面作用域停止，迟到命令不得重启声音。

**用户确认的策略调整：离页立即释放场景、纹理、声音和业务活动，允许空闲服务暂留，由系统回收。** 这是为避开实测的频繁重启限制；不能再把“系统中只有一个服务进程”作为指标。稳定阅读时仅当前页推进业务，切页短暂持有两页；失败进程按连接确认的身份终止，退出整书清理本应用已知服务。不按名称批量杀进程。

隔离范围为普通场景崩溃和业务卡死；不是任意恶意插件的沙箱，也不隔离显卡驱动或整机资源耗尽。

## 4. 存储、声音和兼容

保留应用标识 `local.ssr.forestbook`、校准和声音设置键。森林旧 `resident.json` 由描述声明，通过页面存储适配器继续读写；整书阅读位置单独保存。页面自身解释与迁移状态。未来版本／主备损坏时保留文件并禁止覆盖，不以清空数据伪装恢复。

声音由 `PageAudioScopes` 统一管理一次性声音、循环声音、静音与暂停恢复；页面只输出声音标识。真实呼噜录音和加工工具随森林资源保留，测试不访问用户正式设置或存档。

## 5. Cursor 与 Codex 工作方式

仓库共同规则：`AGENTS.md`、`docs/engineering/PAGE_CONTRACT.md`、`SCENE_WORKFLOW.md` 和 `TASK_HANDOFF_TEMPLATE.md`。Cursor 的规则入口只引用共同文件。

从已验收主分支创建独立工作目录，例如：

```bash
git worktree add ../mac-popup-book-town -b scene/pocket-town main
cd ../mac-popup-book-town
python3 scripts/page.py new pocket-town
python3 scripts/page.py check pocket-town
python3 scripts/page.py build pocket-town
```

Cursor 负责场景实现及测试，默认只改自己的包；共享协议不足时先单独提出并集成公共变更，再更新场景基线。Codex 负责任务、接口审查、独立验证和必要修复。模板不等于完成玩法，也不自动发布页面。

预览命令 `python3 scripts/page.py preview pocket-town` 会主动打开窗口，仅需要看实际效果时使用。预览采用独立应用标识、临时存储和手动展开，不抢主程序传感器。

完成后提交代码、证据、基线、限制和交接单。集成者合并分支并更新发布清单，再对合并结果运行整书检查；本地合并与远程推送分别授权。

## 6. 统一检查入口

| 命令 | 用途 |
|---|---|
| `bash scripts/format.sh --check shared` | 公共模块格式 |
| `python3 scripts/check-boundaries.py --shared` | 公共依赖与目录边界 |
| `bash scripts/test.sh` | 确定性共享测试，不打开硬件／窗口 |
| `python3 scripts/page.py check <id>` | 只检查指定页面及契约 |
| `python3 scripts/page.py build <id>` | 只打包指定页预览，不启动 |
| `bash scripts/check.sh` | 公共检查、已发布页面测试及正式打包 |
| `bash scripts/integration.sh` | 无窗口后台进程、故障、开合和互动回归 |
| `bash scripts/build.sh` | 严格构建当前发布清单 |

默认成品：`build/林间小屋.app`。缓存、应用、临时存档、截图及测量输出均在忽略目录。持续集成配置覆盖公共模块、场景矩阵与整书打包；本轮没有远程推送，不能宣称线上流程已经执行。

调试默认后台运行，不抢焦点；确需前台验收时提前说明并集中展示。后台离屏消费帧率不能当作屏幕呈现帧率，真实鼠标、物理合盖和主观试听分别验收。
