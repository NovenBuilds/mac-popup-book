# 《打开，一本小世界》六跨页场景与整书规划

定稿与保存日期：2026-10-27。

状态：场景与整书规划已定稿并保存，尚未启动新场景开发。本文属于研究规划，不进入代码仓库；《林间小屋》原七阶段文档全部保留，其后续迭代仍停止。

## 一、整本书的定位

制作一本在 MacBook 上展开的互动立体书：**屏幕开合决定这一页的空间如何撑起，翻页带人进入另一个小世界，停下来则有一件值得亲手玩的事情。**

全书包含六个跨页，顺序为：

**林间小屋 → 口袋小镇 → 住在电脑里的小屋 → 海底剧场 → 机械天文馆 → 大语言模型演化史。**

《林间小屋》保留当前版本，不恢复此前的七阶段深化计划。“私人回忆”由“大语言模型演化史”替换；“纸上森林”不另立章节，其森林意象由现有第一页承接。沿用最初构想中“展开有机关、停留有互动、收合有回应”的结构。

每个新跨页具备：

- 一个首次展开时能看懂的视觉中心。
- 一个可重复操作、结果可变化的核心玩法。
- 三处左右不抢注意力的小细节。
- 一段与该场景相符的收合演出。
- 不操作时仍自然成立的安静状态。

不把这些页面扩展为五个复杂游戏，也不依靠签到、任务列表和关系养成延长停留。

## 二、统一书本，不同世界

### 书本的共同语言

统一书页尺寸、书脊、纸张厚度、页码、书签位置、基本观察方向和控制方式。所有场景都必须有可辨认的“折平—半立起—完全展开”结构，不能仅靠整体缩放或淡入出现。

各页材质不同：

| 跨页 | 主要材质与色彩 | 情绪 |
|---|---|---|
| 林间小屋 | 奶油纸、橘色纸猫、森林绿 | 温暖、安静 |
| 口袋小镇 | 彩绘木片、压纹纸、黄铜轨道 | 轻快、精巧 |
| 电脑里的小屋 | 木质家具、织物、磨砂灯罩、纸质墙壁 | 私密、舒适 |
| 海底剧场 | 半透明薄片、珠光纸、柔和水纹 | 轻盈、流动 |
| 机械天文馆 | 深蓝纸、黄铜、搪瓷星球 | 庄严、好奇 |
| 模型演化史 | 打字纸带、透明线路、印刷模块 | 清晰、探索 |

采用**有厚度的立体书机关＋局部完整三维物件**。建筑主体、桌椅、列车、星球可以有体积；墙壁、海草、背景、说明牌仍保留可折叠结构。不同材质通过相同书页与机关连接，避免变成六个无关的三维演示。

### 开合与翻页

- 保留当前角度映射、校准、平滑和手动预览。
- 铰链只控制当前页展开程度，不自动翻页。
- 提供前后页按钮、方向键和目录；触控板双指横向手势作为等价入口。
- 正常翻页按“当前机关折平 → 纸页绕书脊翻转 → 新机关按当前角度展开”进行，目标总时长约一秒。
- 翻页过程中暂不接收场景操作和新的翻页请求，不堆积动作。
- 物理快速收合优先于演出；接近收合时暂缓翻页，重新打开后继续。
- 目录可直接选择跨页，但仍经过统一的折平与翻纸过程。
- 不强制阅读顺序、不锁章节，首次默认从《林间小屋》进入。

整本书的声音默认静音。翻页时旧页声音退出，新页声音渐入；不同时播放两个世界的环境声。

## 三、五个新跨页的场景设计

### 第二跨页：口袋小镇——“让最后一班小火车绕镇一周”

**画面描述**

> 打开书页，一条弯曲的河流先露出来。两岸的彩色房屋像连在一起的折纸街道逐层站起，中央钟楼升高，一座小桥跨过书脊。列车从车站的阴影里探出车头，车窗依次亮起。

构图由左侧车站、中央钟楼与广场、右侧河岸街区组成。轨道绕镇形成两个可切换的环路，前景保留清楚可点击的道岔。

**展开与收合**

- 前段：河道、地面与轨道露出。
- 中段：街屋、桥梁、钟楼依次立起。
- 后段：站台棚展开，列车准备出发。
- 收合：停止发车，列车按剩余空间驶入最近的遮挡位置；慢收合完整回站，快收合在站棚或隧道后隐藏。

**唯一核心玩法：调道岔，安排列车路线**

点击道岔切换“河岸线／钟楼线”，再点击车站发车。列车经过不同路线，引发不同街景回应：桥边小旗摆动、广场人物让路、钟楼钟面转动。

道岔正在被列车占用时不可切换，有明确的短暂状态提示。运行中再次点击发车不生成第二列车。

**停留细节**

屋内灯光偶尔变化；站台纸人交换位置；列车停靠时有一位乘客上下车。细节跟随运行状态，不固定每隔几秒重复同一套表演。

**素材与声音**

房屋立面、钟楼、桥、车站、轨道和道岔分件；列车需要车轮与车身独立控制。声音包括轻微车轮节奏、道岔卡嗒、短促到站铃，避免持续汽笛。

**验收重点**

用户不读说明也能切换路线；一轮结束后可以立即尝试另一条；半开时桥、屋、轨道依然呈现明确空间关系。

### 第三跨页：住在电脑里的小屋——“拨动房间里的一小段时光”

**画面描述**

> 两面墙从纸页上向外撑开，露出一个剖开的微缩房间。床、书桌、窗台和吊灯分别从自己的折线立起。一位小房客推开薄薄的被子，走向窗边。房间不大，却有刚刚有人生活过的痕迹。

与《林间小屋》区分：这里强调**房间内部、家具机关与光线变化**，不再制作另一套宠物陪伴系统。小房客采用无对白、动作简洁的原创纸偶。

**展开与收合**

地板先展开，墙与家具随后立起，吊灯最后落到位置。收合时房客收起手边物件、回到床边，吊灯熄灭，家具折回墙面与地板。

**唯一核心玩法：拖动“房间时光”纸拉条**

拉条包含清晨、午后、夜晚三个可停留位置，中间连续过渡。它控制虚构房间的时间，不读取真实系统时间。

- 清晨：光斑越过床边，房客整理被子、开窗。
- 午后：房客在桌边阅读或写字，窗帘轻动。
- 夜晚：窗外变暗，台灯亮起，房客换到扶手椅。

改变时光后，光线立即响应；房客完成当前短动作后接入新状态。快速拖动只跟随最后目标，不补播整天活动。

**停留细节**

书页翻动、杯口少量热气、窗台植物投影。没有输入时维持当前时间里的日常，不自动循环一天。

**素材与声音**

床、桌椅、门窗、台灯、拉条、小房客分件；角色首版只需起身、短距离行走、坐下、阅读四组动作。声音以翻书、椅脚、窗扣和灯开关为主。

**验收重点**

时间拉条与物理开合互不干扰；三个时段都有显著构图差异；来回拖动不会让房客瞬移或重复生成道具。

### 第四跨页：海底剧场——“用一股水流，带鱼群穿过珊瑚”

**画面描述**

> 珍珠色的书页像海床一样舒展开。半透明海草向上翻起，珊瑚拱门逐层撑开，蓝绿色的光穿过薄片落在沙地上。一群小鱼从珊瑚背后游出，远处的水母缓慢升起。

主景为中央珊瑚拱门，左侧海草区、右侧贝壳台，鱼群在前后层之间穿行。水的感觉主要由光纹、透明材质和生物运动建立，不依赖复杂流体模拟。

**展开与收合**

海床、珊瑚、海草分层展开；鱼群只在具备足够空间后进入。收合时鱼群退到珊瑚遮挡后，海草贴回纸面，水纹渐弱。

**唯一核心玩法：拖动水流珠，引导鱼群**

按住页面上的透明水流珠并移动，生成有方向的柔和流线；鱼群逐渐转向，绕过珊瑚，穿越拱门。松手后水流衰减，鱼群恢复巡游。

提供三个点击式水流位置，作为无需拖动的替代操作。鱼群遵循引导但不紧贴指针，不追求精确操控。

**停留细节**

鱼群通过拱门后形态变化；海草随附近流向摆动；贝壳在鱼群靠近时短暂张开。所有变化围绕同一套水流玩法，不增加收集任务。

**素材与声音**

珊瑚分层、海草分段、少量鱼类与水母、贝壳可动部件。鱼群采用受限路径与局部避让，不做通用生态系统。声音为低音量水下氛围与少量气泡，避免循环滴答和尖锐高频。

**验收重点**

水流方向可看懂、鱼群响应可观察；透明层没有明显排序错误；鱼不会穿过书页或在收合时悬在场外。

### 第五跨页：机械天文馆——“亲手转动一套小小的日月机关”

**画面描述**

> 深蓝纸页撑起几层星空，黄铜支架从书脊两侧展开。中央太阳亮起，地球与月球沿细窄轨道升到各自的位置。前景一只小曲柄像在邀请你：转一下，看看影子会发生什么。

首版只制作**太阳、地球、月球的一套机械模型**，不同时铺开多个星系。

**展开与收合**

底座与支架先展开，轨道环随后竖起，星球最后到位。收合时轨道环旋回同一平面，星球落入对应凹位；展示相位保留，下次展开继续。

**唯一核心玩法：转动曲柄，观察日月变化**

拖动曲柄或按左右控制，使装置沿统一时间方向推进；可暂停在任意位置，观察地球昼夜、月球受光面及相对位置。

提供三个清晰的观察停靠点，帮助用户发现变化，但不要求答题。角度控制机关展开，曲柄控制天体运动，二者不混用。

**停留细节**

黄铜刻度转动、星球阴影移动、背景星图轻微闪烁。靠近观察点时出现一句解释，离开后收起。

**素材与声音**

球体、轨道、支架、齿轮与曲柄分别制作。明确标注“机械示意：尺寸、距离与运行速度经过压缩”，不宣称实时天象或精确天文仿真。

声音使用低强度机械转动与停靠轻响，不随每个微小输入连续触发齿轮音。

**验收重点**

旋转、暂停、反向均连续；月球受光表现与解释一致；几何示意没有被当作精确比例呈现。

### 第六跨页：文字如何长出能力——大语言模型演化史

**画面描述**

> 一卷印着词语的纸带从左页伸出，穿过几座透明的小装置。注意力线路像细桥一样连接词卡，预训练书架向后展开，人类反馈台竖起选择牌，图像卡片从另一条轨道汇入。最右侧留着一张仍在研究中的工作台。

这是一页**可操作的技术展览**。不扮演真实在线模型，不需要账号或付费接口，不把预制结果伪装成实时生成。

**展开与收合**

各技术装置按空间层级展开，纸带贯穿其中。展开程度不等于模型能力等级；打开后仍可自由选择任何展台。收合时文字收回纸带，各装置折回对应卡槽。

**唯一核心玩法：给同一个例子，换一种处理方式**

首版提供三组固定例子：续写一句话、按要求改写、根据图文做判断。用户选择例子，再切换展台，观察相应的示意与预制结果；不适用于该例子的展台直接解释原因，不编造对比结果。

展台内容分为：

| 展台 | 可见机关 | 想传达的区别 |
|---|---|---|
| 序章：接续文字 | 词卡和候选分支 | 语言模型通过上下文预测后续内容 |
| 注意力 | 可选择、可高亮的词卡连线 | 处理当前位置时，可以利用不同位置的信息 |
| 预训练 | 大量书页汇入共享装置 | 从大量文本学习，再用于不同任务 |
| 指令与人类反馈 | 请求卡、示范卡和比较选择台 | 会接续文字，与更符合用户意图，是不同目标 |
| 多模态 | 图像卡与文字纸带共同进入装置 | 输入不再只有文字 |
| 分支研究台 | 分步卡片、检索与工具抽屉 | 提示方法、外部工具和模型训练是不同层面的改进 |

技术路线采用主线加分支，不能暗示所有技术按展台顺序首次出现，也不能暗示后一项完全取代前一项。

**停留细节与边界**

选中装置时只有相关线路亮起；每站一句人话解释，另有可展开的研究来源。注意力连线标注为示意，不冒充真实权重；分步文字不被解释为可直接观察的内部思维。

代表节点采用已核对的研究：2017 年注意力架构、2018 年生成式预训练、2022 年人类反馈指令训练、2023 年图文模型报告；分步提示与工具使用作为并行研究分支。此页是代表性机制选讲，不标榜完整覆盖截至 2026 年的全部发展。

**研究依据，核对日期：2026-10-27**

- [《Attention Is All You Need》：注意力架构](https://arxiv.org/abs/1706.03762)。
- [《Improving Language Understanding by Generative Pre-Training》：生成式预训练](https://cdn.openai.com/research-covers/language-unsupervised/language_understanding_paper.pdf)。
- [《Training language models to follow instructions with human feedback》：人类反馈与指令训练](https://arxiv.org/abs/2203.02155)。
- [《GPT-4 Technical Report》：图像与文字输入](https://arxiv.org/abs/2303.08774)。
- [分步提示研究](https://arxiv.org/abs/2201.11903)、[推理与外部行动结合的研究](https://arxiv.org/abs/2210.03629)。

**验收重点**

用户能说清至少两种机制的差异；所有展示明确区分史实与视觉比喻；没有需要联网才能完成的核心操作。

## 四、实现组织与制作顺序

### 共享能力与页面边界

复用当前角度读取、平滑、声音输出、多语言、纸片几何和取景能力；不把新场景塞进《林间小屋》的场景类。

新增统一的“跨页”接口，负责页面身份、进入退出、展开更新、交互和页面状态保存。书本调度器管理当前页、翻页、目录和资源生命周期。具体页面管理自己的玩法，不识别其他页面。

补充通用场景对象标识与点击、拖动、取消事件，不能继续将所有操作都包装成角色互动。现有猫作为第一页的角色内容保留；没有角色的页面不创建虚假角色来满足接口。

角度与时钟由整本书统一提供，不能每页分别打开传感器、创建计时器。页面停止显示时停止声音与更新；只保留当前页运行资源，翻页期间短暂持有目标页。

保存最后阅读页和少量页面选择，例如列车路线、房间时段、天文馆相位。鱼群即时位置等瞬时状态不持久化。《林间小屋》的既有记忆与设置保持兼容。

### 制作顺序

1. **整书骨架＋口袋小镇样页**：以现有第一页和小镇灰盒验证翻页、共享输入、不同玩法与声音切换。
2. **小镇完整样件**：完成美术、列车玩法和三种开合状态，作为后续页面的制作标准。
3. **电脑里的小屋**：验证室内折叠、角色与虚构时间独立运行。
4. **海底剧场**：集中验证透明材质、鱼群运动与交互可读性。
5. **机械天文馆**：验证联动机关与知识解释。
6. **模型演化史**：先审定内容与比喻，再制作装置和例子。
7. **整书统一打磨**：调整节奏、取景、声音响度、目录、多语言与连续翻阅体验。

每页都先交付展开、半开、收合三态样张及可运行灰盒，再制作批量资产。保留可编辑源文件、运行资产、声音原始文件和来源记录；不默认采购或启用付费生成服务。

## 五、验收与本地文档交付

**单页验收**

- 首次展开能辨认主要机关，半开仍有空间关系，快速收合不穿插。
- 用户能找到核心操作，操作后立即出现可见反馈；重复操作不堆积动作。
- 核心玩法至少有两种可观察结果；停住时不自动恢复或强迫继续操作。
- 所有拖动提供点击或键盘替代方式；减少动态效果时仍能完成玩法。
- 图文说明、声音与画面一致，中英文均不截断。

**整书验收**

- 六页可按顺序翻阅、反向翻阅及目录跳转。
