## 1．体验目标与范围

让同一个小屋在用户做别的事时也能安静陪伴，声音与情境回应可主动选择。必做标准/小窗运行策略、分层声音、四种模式与音频特征；不做语音转录、会议内容识别、音乐曲名识别、自动专业舞种分类或云端音频上传。

## 2．前置条件与现状差距

依赖前四阶段的行为、内容、可暂停声音与存档。当前失去焦点即暂停，不能直接称为桌面陪伴；声音为短合成环境循环。先记录S4连续运行的资源基线，再改变运行策略。

基础目标继续为macOS14及Apple Silicon；系统音频捕获使用按API可用性分支，不为了单项声音功能整体抬高最低系统版本。

## 3．产品行为规格

### 3.1 三个子阶段与生命周期

先完成A小窗和低干扰运行，再完成B声音分层，最后完成C情境分析。A/B必须在没有任何捕获权限时完整工作。

| 场景 | 标准窗口 | 用户明确开启的小窗陪伴 |
|---|---|---|
| 前台可见 | 完整交互，目标60帧 | 目标30帧，可直接交互 |
| 失去焦点但仍可见 | 延续当前暂停规则 | 继续低功耗行为，动画目标24帧，不抢焦点 |
| 最小化/主动暂停 | 停止行为、捕获与声音 | 同样停止，不把最小化当后台播放请求 |
| 全部被遮挡/屏幕锁定 | 暂停 | 暂停，必要时保留最低频状态通知，不分析音视频 |
| 系统睡眠 | 停止全部输入、时钟和声音 | 同样停止，不持有防睡眠断言 |
| 关闭小窗 | 不影响其他仍可见标准窗 | 关闭陪伴会话；最后一个窗口关闭则退出 |

小窗默认可移动、可缩放、不全局置顶；用户可选择置顶，不覆盖系统安全界面。收起控制条仍保留暂停/静音入口。普通模式与小窗共用一个会话及存档，避免两只猫同时推进；切换只改变承载窗口，不复制世界。

### 3.2 四种陪伴方式

| 模式 | 输入与行为 | 主动打扰限制 |
|---|---|---|
| 安静 | 无捕获；呼吸、坐卧、偶尔观察 | 不主动猫叫；不弹出剧情面板 |
| 工作 | 用户手动选择；猫安坐、整理、短暂看看用户 | 事件主动邀请至少间隔10分钟，默认不鸣叫，不监听键盘内容 |
| 音乐 | 用户选系统输出音频；节奏强弱驱动动作 | 无信号恢复安静；不会因每个峰值叫一声 |
| 倾听 | 用户主动选择麦克风；耳朵转向和停顿时轻回应 | 回应至少间隔60秒，不打断说话，不猜谈话内容 |

音乐动作分轻柔摇摆、轻快踩步、活泼跳步三组。用户可固定组别，默认按稳定强弱切换；不将三组包装成曲风识别。节奏不稳定时仅做缓慢身体起伏，不突然加速。停歌2秒内淡回坐卧。用户抚摸优先于音乐动作，释放后至少3秒平滑恢复。

### 3.3 音频捕获与特征

- 系统输出与麦克风分开选择、分开申请权限，不以选择音乐模式等同同意麦克风。进入模式先解释来源，点击“开始感应”才调用系统授权。
- 默认用Core Audio进程音频分流接口捕获系统输出；本机SDK标明创建接口起于macOS14.2。执行时核对实际SDK与目标版本；14.0/14.1或接口失败时保留手动节奏预览，不自动改用要求更广权限的屏幕捕获。
- 系统捕获排除本应用音频，保持原音乐正常播放，不静音源进程。麦克风倾听时默认关闭应用猫叫，仅低音量环境或完全静音，降低自反馈；使用耳机仍进行峰值/自身播放抑制。
- 只在内存计算音量包络、起音、节拍候选及置信度；默认48kHz分析，降采样单声道处理；给行为层每秒最多20次特征，不传原始音频。
- 开始感应、静音输入、无权限、设备移除与处理中使用不同状态，不把零值当权限成功。撤销后立即停止、显示可重试入口；不反复弹权限提示。
- 特征窗口不超过8秒且只在内存，停止立即释放。不录文件、不转录、不保存麦克风内容；开发记录只存合成测试信号与非内容性能计数。

### 3.4 分层声音

环境、动作、猫表达分别调音量，主静音最高优先。环境改为风、树叶、远鸟等至少3层，变间隔和起点，不形成固定8秒重复；同时活跃环境层最多2层。

全局同时最多6个声音，其中猫表达一次只播一个；脚步/纸声限流，优先保留用户直接互动反馈。切换环境淡变1～2秒；停止/失焦暂停后不补播历史队列。真实录音风格统一，按S2许可登记。

## 5．工程与素材要求

- 核心增加类型化 `CompanionMode`（陪伴模式）、`AudioFeatures`（非内容音频特征）及能力/授权状态；角色行为解释特征，平台不输出猫动作。
- 运行层引入可注入运行策略，用窗口可见性、用户模式、睡眠状态决定采样/动画/声音；不再把全部决定塞进一个active布尔值。保留代次保护，迟到音频特征不覆盖新模式。
- 音频捕获、特征计算与播放职责分开；平台工作队列处理音频，主线程只消费低频特征。可复用的信号处理单独纯逻辑目录，不导入界面/角色模块。
- 模式与音量可保存，捕获默认关闭；重启只恢复所选模式和意图提示，不自动重新开启麦克风。新会话用户主动开始感应后才采集。
- 源音频、自录与加工工程按S2资产规则交付；三套舞动属于猫表现，复用骨骼与动作混合，不增加舞蹈选择商城。

## 6．测试与验收

**自动检查：**完整生命周期矩阵、窗口切换、过期音频回调、四模式优先级；60/90/120/150拍每分钟合成节拍稳定段允许倍/半拍归一后误差≤5%，噪声与弱置信度必须回落；停止、设备变化、自身播放抑制；无权限仍可手动。

**本机验证：**系统与麦克风逐项申请/拒绝/撤销，耳机/扬声器与设备切换；选择来源后核对原音乐不被静音；真实失焦、遮挡、锁屏、最小化和睡眠恢复。录音指示及资源释放与界面一致。

**资源：**同机同画质比较标准60帧和陪伴低帧率，各测30分钟CPU/GPU、内存、热状态与帧时间；低功耗空闲CPU/GPU平均负载分别不高于标准模式70%作为首轮目标。持续两小时预热后内存相对第15分钟增长不超过10%，超出需定位缓存/泄漏再验收；这些是预算，不是当前性能结论。

**真实体验：**工作30分钟、听歌20分钟、倾听10分钟；记录被打扰次数、是否自愿留窗、动作是否跟音乐而不是乱跳。权限关闭后重做10分钟，核心相处必须完整。
