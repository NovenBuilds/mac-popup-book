## 模块职责

| 模块 | 职责 |
| --- | --- |
| PopupBookCore | 基础值、角度映射与协议 |
| PopupBookRuntime | 可注入输入、时钟、场景、角色、声音和存储的调度 |
| MacPlatform | 串行硬件访问、系统生命周期、设置与音频 |
| SceneKitRendering | 通用几何、渲染承载、角色标识命中 |
| PaperCatBehavior | 纯逻辑猫行为、姿态、一次性事件 |
| PaperCatRendering | 猫造型、姿态表现、猫音效资源映射 |
| ForestCabinScene | 林间小屋场景、折叠层和通用锚点，不创建猫 |
| ForestCabinApp | 中文界面和具体依赖组装 |

核心和调度不引用图形、设备或具体猫类型；非猫测试角色用整数姿态运行同一调度路径。场景不创建角色；角色表现通过关联类型匹配姿态。界面仅通过通用控制接口发出意图。传感器和时钟停止后通过代次标识拒绝旧回调。

## 验证边界

本轮没有让用户物理开合十次、真实睡眠唤醒、试听或逐项确认原有设置。自动化窗口检查中的活动状态与睡眠通知可控注入，几何命中不等于真实鼠标点击。计算机界面工具能读取到最终应用窗口与控件，但未可靠切到应用前台，因此不将此作为真实焦点切换通过的证据。历史用户验收仍是此前版本的人工证据；本轮真实硬件证据仅为传感器读取，不能替代完整体验验收。
