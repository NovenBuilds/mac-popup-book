用这一份做真实开合、试听和前台 30 分钟性能。远程自动验收只证明工程检查、后台隔离和五页离屏集成，不能当作本单通过。签名、公证、异机安装和五人试玩仍是范围外，不在本单。

## 开始前

- 优先用独立的 macOS 测试账户。没有该账户、也没有明确同意改用日常账户时，不要打开日常账户里的 `~/Library/Application Support/local.ssr.forestbook/` 存档。
- 记录机型、系统版本和显示分辨率。US2 全程保持同一分辨率。
- 先做 US1，再单独重新启动应用做 US2，不要接在同一轮操作后面继续计时。
- 原始截图、功耗输出和日志放在本机 `build/candidate-checks/manual/`，不要提交到仓库。观察结果回写 `local-session.md` 和 `performance-session.md`。

## US1 前台、物理开合、输入和声音

对照 [成品验收标准](../../../docs/engineering/RELEASE_ACCEPTANCE.md)。每项写下通过、未通过或待验收（缺条件时注明）。

### 五页前台

收合、半开、全开各有稳定轮廓；核心输入立刻有可见反馈；启用和静音时声音正确，无旧页串声。

| 页面 | 收合 | 半开 | 全开 | 核心互动 | 结论 |
|---|---|---|---|---|---|
| 林间小屋 |  |  |  | 邀请、轻抚；合上或离开后再回来，相处记录仍可用 |  |
| 口袋小镇 |  |  |  | 两条环线的街景回应、道岔、列车驶离/回站/收起；超过 90° 会运行 |  |
| 窗边小屋 |  |  |  | 三段时光的灯光和动作；61°–64° 停住和反向时房客连续 |  |
| 海底剧场 |  |  |  | 两个水流方向下鱼群轨迹不同；松手恢复巡游 |  |
| 机械天文馆 |  |  |  | 曲柄、暂停、月相停靠；切页后相位恢复 |  |

### 物理开合

需要真实铰链。没有铰链时，这些项保持待验收，手动开合仍可单独记录。

| 项目 | 通过条件 | 结论 |
|---|---|---|
| 慢开 | 结构沿折线展开，无明显穿插、悬空或瞬移 |  |
| 快合 | 快合同样稳定，收起的主角回位或被遮挡 |  |
| 半开反向 | 中途反向后进度连续，与手动开合是同一场景进度 |  |
| 合盖唤醒 | 合盖后再打开，书能回到可继续的状态 |  |
| 小镇超过 90° | 实测超过 90° 时列车按设计运行 |  |
| 真实失联约 1 秒后的暂停与恢复 | 信号失联后暂停，恢复后能继续 |  |

### 输入和声音

鼠标、触控板、窗口内替代按钮至少各做一次核心操作。再切换手动开合、静音和翻页，检查提示、声音、旧页串声和可重试状态。缺某一种输入时，只把该项留为待验收。
